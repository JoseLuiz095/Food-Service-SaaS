TURNSTILE - IMPORTANTE
FloriWeb e FoodWeb compartilham o mesmo Supabase Auth. O Supabase possui a configuracao CAPTCHA do projeto e valida os tokens com o Secret configurado ali. Se cada frontend usar um widget Turnstile diferente, o token do FoodWeb pode ser validado com o Secret do widget do FloriWeb e retornar invalid-input-secret.

Como o FloriWeb esta funcionando:
1. Abra o widget Turnstile usado pelo FloriWeb (Site Key 0x4AAAAAAEeGYovN4CVuiF_x).
2. Adicione foodweb.joseluizacama.workers.dev nos hostnames permitidos desse MESMO widget.
3. No Cloudflare Build do FoodWeb configure:
   VITE_TURNSTILE_SITE_KEY=0x4AAAAAAEeGYovN4CVuiF_x
4. Mantenha no Supabase Auth o Secret do widget que ja funciona no FloriWeb.
5. Gere novo deployment do FoodWeb.

Nao coloque o Secret em VITE_* nem no GitHub.
